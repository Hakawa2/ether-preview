# Universal Constitution (FIRE)

## Core Principles
1. **User Experience First**: Keep UI aligned with Stitch mockups and tokens.
2. **Quality & Type Safety**: Zero TypeScript errors, lint warnings addressed.
3. **Preserve Rules**: Never execute npm run start/build/test without user confirmation. Use `npx skills add <skill>` if requested.
4. **Performance**: Smooth 60fps animations, lazy loading for off-screen images.
